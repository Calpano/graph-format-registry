= sparse6
:toc:

A compact ASCII encoding for undirected graphs, designed by Brendan McKay for
the nauty toolkit. Unlike link:../graph6/graph6.adoc[graph6] it is optimized for sparse graphs, encoding the
edge list rather than the full adjacency matrix.

== Identity

[source]
----
format:sparse6 ..has type.. format
format:sparse6 ..category.. text
format:sparse6 ..label.. sparse6
format:sparse6 ..file extension.. .s6
format:sparse6 ..file extension.. .sparse6
format:sparse6 ..author.. brendan-mckay
format:sparse6 ..spec.. https://users.cecs.anu.edu.au/~bdm/data/formats.txt

brendan-mckay ..has type.. person
brendan-mckay ..label.. Brendan McKay
----

== Features

[source]
----
format:sparse6 ..supports.. nodes
format:sparse6 ..supports.. undirected-edges
format:sparse6 ..lacks.. directed-edges
format:sparse6 ..lacks.. node-labels
format:sparse6 ..lacks.. edge-labels
format:sparse6 ..lacks.. attributes-on-nodes
format:sparse6 ..lacks.. attributes-on-edges
format:sparse6 ..lacks.. typed-edges
----
