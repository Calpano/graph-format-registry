= digraph6
:toc:

A compact ASCII encoding for directed graphs, designed by Brendan McKay for the
nauty toolkit. It encodes the full (possibly asymmetric) adjacency matrix,
making it the directed counterpart of link:../graph6/graph6.adoc[graph6].

== Identity

[source]
----
format:digraph6 ..has type.. format
format:digraph6 ..category.. text
format:digraph6 ..label.. digraph6
format:digraph6 ..file extension.. .d6
format:digraph6 ..file extension.. .digraph6
format:digraph6 ..author.. brendan-mckay
format:digraph6 ..spec.. https://users.cecs.anu.edu.au/~bdm/data/formats.txt

brendan-mckay ..has type.. person
brendan-mckay ..label.. Brendan McKay
----

== Features

[source]
----
format:digraph6 ..supports.. nodes
format:digraph6 ..supports.. directed-edges
format:digraph6 ..lacks.. undirected-edges
format:digraph6 ..lacks.. node-labels
format:digraph6 ..lacks.. edge-labels
format:digraph6 ..lacks.. attributes-on-nodes
format:digraph6 ..lacks.. attributes-on-edges
format:digraph6 ..lacks.. typed-edges
----
