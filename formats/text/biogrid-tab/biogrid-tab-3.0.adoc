== Features

[source]
----
format:biogrid-tab-3.0 ..supports.. nodes
format:biogrid-tab-3.0 ..supports.. undirected-edges ,, Interactions
format:biogrid-tab-3.0 ..supports.. parallel-edges ,, Multiple interaction records for the same pair (distinct evidence)
format:biogrid-tab-3.0 ..supports.. self-loops ,, Self-interactions are representable
----
