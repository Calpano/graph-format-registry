= Harwell-Boeing
:toc:

A fixed-format, 80-column ASCII format for exchanging sparse matrices. Graphs
are represented as sparse adjacency matrices. Largely superseded by link:../../text/matrix-market/matrix-market.adoc[Matrix
Market], but still widely used for test-matrix collections.
