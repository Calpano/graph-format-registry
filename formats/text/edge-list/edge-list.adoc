= Edge List
:toc:

Simple list of edges, optionally with weights.

== Identity

[source]
----
format:edge-list ..has type.. format
format:edge-list ..category.. text
format:edge-list ..label.. Edge List
format:edge-list ..file extension.. .edgelist
format:edge-list ..spec.. https://networkx.org/documentation/stable/reference/readwrite/edgelist.html
----

format:edge-list ..lacks.. mixed-directionality-edges
format:edge-list ..lacks.. hyperedges
format:edge-list ..lacks.. edges-on-edges

format:edge-list ..lacks.. edge-labels
format:edge-list ..lacks.. attributes-on-nodes

..status.. partial

,,
format:edge-list ..lacks.. attributes-on-graphs
format:edge-list ..lacks.. typed-edges
----
