= Mermaid State Diagram
:toc:

The state-diagram type of link:mermaid.adoc[Mermaid], opened by the
`stateDiagram` (or `stateDiagram-v2`) keyword. States are nodes and transitions
are directed edges labelled with their trigger; composite states nest other
states. The `[*]` token marks the start/end pseudo-state.
