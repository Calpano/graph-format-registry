= Mermaid Mindmap
:toc:

The mindmap type of link:mermaid.adoc[Mermaid], opened by the `mindmap` keyword.
Indentation defines a strict hierarchy: each node attaches to the nearest
less-indented node, so the document is a tree of labelled nodes.

== Identity

[source]
----
format:mermaid-mindmap ..has type.. format
format:mermaid-mindmap ..subformat of.. format:mermaid
format:mermaid-mindmap ..category.. text
format:mermaid-mindmap ..label.. Mermaid Mindmap
format:mermaid-mindmap ..spec.. https://mermaid.js.org/syntax/mindmap.html
----

== Features

[source]
----
format:mermaid-mindmap ..lacks.. multiple-graphs-per-document
format:mermaid-mindmap ..supports.. nodes
format:mermaid-mindmap ..lacks.. undirected-edges
format:mermaid-mindmap ..supports.. directed-edges ,, Implicit parent-to-child edges from indentation
format:mermaid-mindmap ..lacks.. mixed-directionality-edges
format:mermaid-mindmap ..lacks.. hyperedges
format:mermaid-mindmap ..lacks.. parallel-edges ,, Tree: one parent edge per node
format:mermaid-mindmap ..lacks.. self-loops ,, Tree: no node attaches to itself
format:mermaid-mindmap ..lacks.. edges-on-edges
format:mermaid-mindmap ..supports.. nested-graphs-in-nodes ,, Indentation hierarchy (tree)
format:mermaid-mindmap ..lacks.. nested-graphs-in-edges
format:mermaid-mindmap ..lacks.. nested-graphs-in-graphs
format:mermaid-mindmap ..supports.. node-labels ,, Label, shape brackets stripped
format:mermaid-mindmap ..lacks.. edge-labels
format:mermaid-mindmap ..lacks.. attributes-on-nodes
format:mermaid-mindmap ..lacks.. attributes-on-edges
format:mermaid-mindmap ..lacks.. attributes-on-graphs
format:mermaid-mindmap ..lacks.. typed-edges
----
