= Mermaid Class Diagram
:toc:

The class-diagram type of link:mermaid.adoc[Mermaid], opened by the
`classDiagram` keyword. Classes are nodes carrying members (attributes and
methods); relationships between classes are edges typed by their relation
(inheritance, composition, aggregation, association, dependency).

== Identity

[source]
----
format:mermaid-class ..has type.. format
format:mermaid-class ..subformat of.. format:mermaid
format:mermaid-class ..category.. text
format:mermaid-class ..label.. Mermaid Class Diagram
format:mermaid-class ..spec.. https://mermaid.js.org/syntax/classDiagram.html
----

== Features

[source]
----
format:mermaid-class ..lacks.. multiple-graphs-per-document
format:mermaid-class ..supports.. nodes ,, Classes
format:mermaid-class ..supports.. undirected-edges ,, Plain association (--)
format:mermaid-class ..supports.. directed-edges ,, Inheritance/association arrows
format:mermaid-class ..lacks.. mixed-directionality-edges
format:mermaid-class ..lacks.. hyperedges
format:mermaid-class ..supports.. parallel-edges ,, Multiple relationships between the same two classes
format:mermaid-class ..supports.. self-loops ,, Self-association on a class
format:mermaid-class ..lacks.. edges-on-edges
format:mermaid-class ..lacks.. nested-graphs-in-nodes
format:mermaid-class ..lacks.. nested-graphs-in-edges
format:mermaid-class ..lacks.. nested-graphs-in-graphs
format:mermaid-class ..supports.. node-labels ,,
..status.. partial
Class name is the id; optional label after :
,,
format:mermaid-class ..supports.. edge-labels ,, Relationship label after :
format:mermaid-class ..supports.. attributes-on-nodes ,, Class members (fields and methods)
format:mermaid-class ..lacks.. attributes-on-edges
format:mermaid-class ..lacks.. attributes-on-graphs
format:mermaid-class ..supports.. typed-edges ,, Inheritance, composition, aggregation, association, dependency
----
