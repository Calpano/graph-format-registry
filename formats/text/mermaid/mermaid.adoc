= Mermaid
:toc:

Mermaid is a text-based diagramming language that renders diagrams from plain
text descriptions. It is not a single graph grammar but a family of *diagram
types*, each with its own syntax, selected by the keyword on the first content
line (e.g. `flowchart`, `classDiagram`, `erDiagram`). The registry models each
diagram type as a sub-format of this umbrella entry — see
link:../../../tools.adoc#_graphinout[GraphInOut]'s `reader-mermaid`, whose per-type
parsers define the split below.

== Identity

[source]
----
format:mermaid ..has type.. format
format:mermaid ..category.. text
format:mermaid ..label.. Mermaid
format:mermaid ..file extension.. .mmd
format:mermaid ..file extension.. .mermaid
format:mermaid ..wikipedia.. https://en.wikipedia.org/wiki/Mermaid_(software)
format:mermaid ..wikidata.. Q110961986
format:mermaid ..spec.. https://mermaid.js.org/
----

== Sub-formats

The diagram types Mermaid provides, each detected by its leading keyword:

* link:mermaid-flowchart.adoc[Mermaid Flowchart] — `flowchart` / `graph`
* link:mermaid-class.adoc[Mermaid Class Diagram] — `classDiagram`
* link:mermaid-state.adoc[Mermaid State Diagram] — `stateDiagram`
* link:mermaid-er.adoc[Mermaid ER Diagram] — `erDiagram`
* link:mermaid-c4.adoc[Mermaid C4 Diagram] — `C4Context` / `C4Container` / …
* link:mermaid-mindmap.adoc[Mermaid Mindmap] — `mindmap`
* link:mermaid-sankey.adoc[Mermaid Sankey] — `sankey-beta` / `sankey`
* link:mermaid-architecture.adoc[Mermaid Architecture] — `architecture-beta` / `architecture`
