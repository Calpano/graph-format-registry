= Mermaid Sankey
:toc:

The Sankey type of link:mermaid.adoc[Mermaid], opened by the `sankey-beta`
keyword. Each line is a weighted flow `source,target,value`; nodes are implied
by the names, and the value is the flow magnitude carried on the directed edge.
