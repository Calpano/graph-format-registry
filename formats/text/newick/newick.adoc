= Newick format
:toc:

A compact text format for representing rooted or unrooted phylogenetic trees
using nested parentheses. Each tree is written as a single expression
terminated by a semicolon, where leaves carry names and branches may carry
lengths.

== Features

[source]
----
format:newick ..lacks.. multiple-graphs-per-document ,, One tree per expression, though some tools concatenate several
format:newick ..supports.. nodes ,, Internal and leaf nodes
format:newick ..supports.. undirected-edges ,, Unrooted trees
format:newick ..supports.. directed-edges ,, Rooted trees imply parent-to-child direction
format:newick ..lacks.. hyperedges
format:newick ..lacks.. mixed-directionality-edges
format:newick ..lacks.. parallel-edges ,, Tree: one branch per node pair
format:newick ..lacks.. self-loops ,, Tree: no node attaches to itself
format:newick ..lacks.. edges-on-edges
format:newick ..lacks.. nested-graphs-in-nodes
format:newick ..lacks.. nested-graphs-in-edges
format:newick ..lacks.. nested-graphs-in-graphs
format:newick ..supports.. node-labels ,, Names on leaf and internal nodes
format:newick ..lacks.. edge-labels
format:newick ..lacks.. attributes-on-nodes
format:newick ..supports.. attributes-on-edges ,, Branch lengths after a colon
format:newick ..lacks.. attributes-on-graphs
format:newick ..lacks.. typed-edges
----
