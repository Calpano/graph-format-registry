= LEMON Graph Format
:toc:

Plain-text format of the link:../../../tools.adoc#_lemon[LEMON] C++ optimization library. Sections begin with `@`
(`@nodes`, `@arcs`, `@edges`, `@attributes`), each defining column-oriented maps;
one node map must be named `label`.

== Identity

[source]
----
format:lemon ..has type.. format
format:lemon ..category.. text
format:lemon ..label.. LEMON Graph Format
format:lemon ..alternative name.. LGF
format:lemon ..file extension.. .lgf
format:lemon ..wikidata.. Q135728625
format:lemon ..org.. Eötvös Loránd University
format:lemon ..spec.. http://lemon.cs.elte.hu/pub/doc/1.3/a00002.html
----

== Features

[source]
----
format:lemon ..lacks.. multiple-graphs-per-document
format:lemon ..supports.. nodes ,, @nodes section
format:lemon ..supports.. undirected-edges ,, @edges section
format:lemon ..supports.. directed-edges ,, @arcs section
format:lemon ..lacks.. hyperedges
format:lemon ..supports.. parallel-edges ,, Multiple arcs/edges between the same nodes
format:lemon ..supports.. self-loops ,, Loop arcs/edges permitted
format:lemon ..lacks.. edges-on-edges
format:lemon ..lacks.. nested-graphs-in-nodes
format:lemon ..lacks.. nested-graphs-in-edges
format:lemon ..lacks.. nested-graphs-in-graphs
format:lemon ..supports.. node-labels ,, Mandatory label map on @nodes
format:lemon ..supports.. edge-labels ,,
..status.. partial
Optional label map on arcs/edges
,,
format:lemon ..supports.. attributes-on-nodes ,, Arbitrary named maps
format:lemon ..supports.. attributes-on-edges ,, Arbitrary named maps
format:lemon ..supports.. attributes-on-graphs ,, @attributes section
format:lemon ..lacks.. typed-edges
----
