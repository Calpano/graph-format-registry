= HELM
:toc:

A hierarchical line-notation format for macromolecules. Monomers act as nodes
and the connection list as edges, with each simple polymer (peptide, RNA,
chemistry) a sub-graph and inter-polymer connections joining them. A monomer can
itself expand to an atom-level molecular graph, giving nested structure.

== Features

[source]
----
format:helm ..supports.. multiple-graphs-per-document ,, Multiple simple polymers per notation
format:helm ..supports.. nodes ,, Monomers as nodes
format:helm ..supports.. undirected-edges ,, Backbone and explicit connections
format:helm ..lacks.. directed-edges
format:helm ..lacks.. hyperedges
format:helm ..lacks.. mixed-directionality-edges
format:helm ..lacks.. parallel-edges ,, Distinct R-group attachment points, not duplicate connections, join a monomer pair
format:helm ..lacks.. self-loops ,, A monomer does not connect to itself
format:helm ..lacks.. edges-on-edges
format:helm ..supports.. nested-graphs-in-nodes ,, A monomer expands to an atom-level structure
format:helm ..lacks.. nested-graphs-in-edges
format:helm ..supports.. nested-graphs-in-graphs ,, Simple polymers nest within the complex polymer
format:helm ..supports.. node-labels ,, Monomer symbols name each node
format:helm ..lacks.. edge-labels
format:helm ..supports.. attributes-on-nodes ,, Per-monomer annotations
format:helm ..supports.. attributes-on-edges ,, Connections specify attachment points (R-groups)
format:helm ..supports.. attributes-on-graphs ,, Extended annotation section
format:helm ..lacks.. typed-edges ,, No bond-type taxonomy; bond determined implicitly by R-group attachment points (an edge attribute, not a type)
----
