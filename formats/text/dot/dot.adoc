= DOT (GraphViz)
:toc:

The DOT format is used by GraphViz for graph description and visualization.

== Identity

[source]
----
format:dot ..has type.. format
format:dot ..category.. text
format:dot ..label.. DOT (GraphViz)
format:dot ..alternative name.. GraphViz
format:dot ..file extension.. .gv
format:dot ..file extension.. .dot
format:dot ..media type.. text/vnd.graphviz
format:dot ..wikipedia.. https://en.wikipedia.org/wiki/DOT_(graph_description_language)
format:dot ..wikidata.. Q900927
format:dot ..author.. emden-gansner
format:dot ..author.. stephen-north
format:dot ..org.. att
format:dot ..spec.. https://graphviz.org/doc/info/lang.html

== Features

Subject is the format id `format:dot`. Use `..supports..` for status = true and
`..lacks..` for status = false; attach a free-text note after `,,`.

[source]
----
format:dot ..lacks.. multiple-graphs-per-document ,, One graph per file
format:dot ..supports.. nodes
format:dot ..supports.. undirected-edges ,, graph with -- operator
format:dot ..supports.. directed-edges ,, digraph with -> operator
format:dot ..lacks.. hyperedges
format:dot ..lacks.. mixed-directionality-edges ,, Graph is either directed or undirected
format:dot ..supports.. parallel-edges ,, Repeated edge statements between the same pair
format:dot ..supports.. self-loops ,, An edge may have the same head and tail
format:dot ..lacks.. edges-on-edges
format:dot ..supports.. nested-graphs-in-nodes ,, Via subgraphs/clusters
format:dot ..lacks.. nested-graphs-in-edges
format:dot ..supports.. nested-graphs-in-graphs ,, Via subgraphs/clusters
format:dot ..supports.. node-labels ,, Via label attribute
format:dot ..supports.. edge-labels ,, Via label attribute
format:dot ..supports.. attributes-on-nodes ,, Extensive attribute system
format:dot ..supports.. attributes-on-edges ,, Extensive attribute system
format:dot ..supports.. attributes-on-graphs ,, Extensive attribute system
format:dot ..lacks.. typed-edges
----
