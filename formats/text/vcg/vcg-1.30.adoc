= VCG (Visualization of Compiler Graphs) 1.30
:toc:

Text format read by the VCG/xvcg tool. A top-level `graph: {}` block contains
`node: {}` and `edge: {}` entries with attributes, and may nest foldable
subgraphs. It is the direct ancestor of the link:../../text/gdl-aisee/gdl-aisee.adoc[aiSee GDL] format.

== Identity

[source]
----
format:vcg ..has type.. format
format:vcg ..category.. text
format:vcg ..label.. VCG (Visualization of Compiler Graphs)
format:vcg ..alternative name.. VCG
format:vcg ..wikidata.. Q105859875
format:vcg ..org.. Universität des Saarlandes
format:vcg ..author.. georg-sander

georg-sander ..has type.. person
georg-sander ..label.. Georg Sander
georg-sander ..affiliation.. Universität des Saarlandes

format:vcg-1.30 ..version of.. format:vcg
format:vcg-1.30 ..version.. 1.30
format:vcg-1.30 ..file extension.. .vcg
format:vcg-1.30 ..spec.. https://www.rw.cdl.uni-saarland.de/people/sander/private/html/gsvcg1.html
----

== Features

[source]
----
format:vcg-1.30 ..lacks.. multiple-graphs-per-document ,, Single top-level graph
format:vcg-1.30 ..supports.. nodes ,, node entries with obligatory title
format:vcg-1.30 ..supports.. undirected-edges ,,
..status.. partial
Only by suppressing arrowheads
,,
format:vcg-1.30 ..supports.. directed-edges ,, source -> target with arrows
format:vcg-1.30 ..lacks.. hyperedges
format:vcg-1.30 ..supports.. mixed-directionality-edges ,,
..status.. partial
Per-edge arrowstyle; undirected is only arrowhead suppression
,,
format:vcg-1.30 ..supports.. parallel-edges ,, Multiple edge entries may share source and target
format:vcg-1.30 ..supports.. self-loops ,, An edge may target its own source node
format:vcg-1.30 ..lacks.. edges-on-edges
format:vcg-1.30 ..supports.. nested-graphs-in-nodes ,, A foldable subgraph collapses into a summary node
format:vcg-1.30 ..lacks.. nested-graphs-in-edges
format:vcg-1.30 ..supports.. nested-graphs-in-graphs ,, Nested subgraph blocks (folding)
format:vcg-1.30 ..supports.. node-labels ,, label distinct from title
format:vcg-1.30 ..supports.. edge-labels ,, label on edges
format:vcg-1.30 ..supports.. attributes-on-nodes ,, color, shape, width, folding
format:vcg-1.30 ..supports.. attributes-on-edges ,, color, thickness, linestyle, priority, class
format:vcg-1.30 ..supports.. attributes-on-graphs ,, layout, orientation, spacing
format:vcg-1.30 ..supports.. typed-edges ,, class attribute names edge classes
----
