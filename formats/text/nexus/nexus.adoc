= Nexus file
:toc:

An extensible, modular text format for systematic and phylogenetic data,
organized into blocks such as TAXA, CHARACTERS and TREES. Trees are embedded
in a TREES block using link:../../text/newick/newick.adoc[Newick] expressions, alongside taxa, alignments and
other comparative data.

== Features

[source]
----
format:nexus ..supports.. multiple-graphs-per-document ,, TREES block may hold several trees
format:nexus ..supports.. nodes ,, Internal and leaf nodes
format:nexus ..supports.. undirected-edges ,, Unrooted trees
format:nexus ..supports.. directed-edges ,, Rooted trees imply parent-to-child direction
format:nexus ..lacks.. hyperedges
format:nexus ..lacks.. mixed-directionality-edges
format:nexus ..lacks.. parallel-edges ,, Tree-based: one branch per node pair
format:nexus ..lacks.. self-loops ,, Tree-based: no node attaches to itself
format:nexus ..lacks.. edges-on-edges
format:nexus ..lacks.. nested-graphs-in-nodes
format:nexus ..lacks.. nested-graphs-in-edges
format:nexus ..lacks.. nested-graphs-in-graphs
format:nexus ..supports.. node-labels ,, Taxon names on leaves
format:nexus ..lacks.. edge-labels
format:nexus ..supports.. attributes-on-edges ,, Branch lengths in Newick tree strings
format:nexus ..supports.. attributes-on-graphs ,, Block-level commands and metadata
format:nexus ..lacks.. typed-edges
----
