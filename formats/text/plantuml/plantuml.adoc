= PlantUML
:toc:

PlantUML is a text language for creating UML (and other) diagrams from a plain
`@startuml … @enduml` description. Like link:../../text/mermaid/mermaid.adoc[Mermaid], it
is an umbrella of distinct diagram types (class, sequence, state, component, …),
each with its own grammar. The registry models the graph-shaped diagram types as
sub-formats of this umbrella entry; only the class diagram is modelled so far —
read and written by link:../../../tools.adoc#_graphinout[GraphInOut] via the
official MIT-licensed PlantUML parser (`reader-plantuml`).

== Identity

[source]
----
format:plantuml ..has type.. format
format:plantuml ..category.. text
format:plantuml ..label.. PlantUML
format:plantuml ..file extension.. .puml
format:plantuml ..file extension.. .plantuml
format:plantuml ..file extension.. .pu
format:plantuml ..file extension.. .iuml
format:plantuml ..author.. Arnaud Roques
format:plantuml ..wikipedia.. https://en.wikipedia.org/wiki/PlantUML
format:plantuml ..wikidata.. Q18346546
format:plantuml ..spec.. https://plantuml.com/
----
