= TripleText Format
:toc:

A minimal, line-based plain-text graph format (a sibling of link:../../text/ddot/ddot.adoc[ddot]). Each non-blank
line is one triple `subject --predicate-- object` (or `--predicate->`), with an
optional trailing `.. meta` for per-edge metadata. Each subject and object
becomes a node; each line becomes a directed edge from subject to object, typed
by the predicate; the `.. meta` is attached to the edge as data (`tt:meta`).
Unlike link:../../text/ddot/ddot.adoc[ddot], it uses `--…--` / `--…->` around the predicate and `..` for metadata.

NOTE: TripleText has been **superseded by the ddot.it format** (`ddot`), which
carries the same triple idea forward with a more compact, Markdown-compatible
syntax. Prefer `ddot` for new data.

== Identity

[source]
----
format:tripletext ..has type.. format
format:tripletext ..category.. text
format:tripletext ..label.. TripleText Format
format:tripletext ..file extension.. .tt.txt
format:tripletext ..file extension.. .tt
format:tripletext ..file extension.. .tripletext
format:tripletext ..file extension.. triple.txt
format:tripletext ..org.. calpano
format:tripletext ..superseded by.. format:ddot
----

== Features

[source]
----
format:tripletext ..supports.. nodes ,, Subjects and objects (identified by their text)
format:tripletext ..supports.. directed-edges ,, Each line is an edge subject -> object
format:tripletext ..lacks.. undirected-edges
format:tripletext ..supports.. typed-edges ,, The predicate is the edge type
format:tripletext ..supports.. attributes-on-edges ,, Optional ".. meta" stored as tt:meta data
format:tripletext ..lacks.. node-labels ,, Node label field exists in the model but is never populated
format:tripletext ..lacks.. edge-labels ,, Predicate is the edge type, not a display label
format:tripletext ..lacks.. attributes-on-nodes
format:tripletext ..lacks.. multiple-graphs-per-document
----
