= SYBYL Line Notation (SLN)
:toc:

A line-notation molecular-graph format from Tripos, comparable to link:../../text/smiles/smiles.adoc[SMILES].
Atoms are nodes, single bonds are implicit and other bonds are explicit
characters (edges). Bracketed `[key=value]` attribute lists can be attached to
both atoms and bonds, giving per-node attributes (charge, isotope) and typed
bonds (bond order, aromaticity).

== Identity

[source]
----
format:sln ..has type.. format
format:sln ..category.. text
format:sln ..label.. SYBYL Line Notation (SLN)
format:sln ..alternative name.. SLN
format:sln ..wikipedia.. https://en.wikipedia.org/wiki/SYBYL_line_notation
format:sln ..wikidata.. Q7395247
format:sln ..org.. Tripos
format:sln ..spec.. https://doi.org/10.1021/ci960109j
----

== Features

[source]
----
format:sln ..supports.. multiple-graphs-per-document ,, Multiple molecules per notation (separated by + ; also . for zero-order)
format:sln ..supports.. nodes ,, Atoms as element symbols
format:sln ..supports.. undirected-edges ,, Bonds are undirected
format:sln ..lacks.. directed-edges
format:sln ..lacks.. hyperedges
format:sln ..lacks.. mixed-directionality-edges
format:sln ..lacks.. parallel-edges ,, Bond order is an attribute, not distinct edges
format:sln ..lacks.. self-loops ,, A bond connects two distinct atoms
format:sln ..lacks.. edges-on-edges
format:sln ..lacks.. nested-graphs-in-nodes
format:sln ..lacks.. nested-graphs-in-edges
format:sln ..lacks.. nested-graphs-in-graphs
format:sln ..lacks.. node-labels
format:sln ..lacks.. edge-labels
format:sln ..supports.. attributes-on-nodes ,, Bracketed atom attribute lists (charge, isotope)
format:sln ..supports.. attributes-on-edges ,, Bracketed bond attribute lists
format:sln ..supports.. attributes-on-graphs ,, Global CT attributes such as NAME and REGID
format:sln ..supports.. typed-edges ,, Bond order and aromaticity as bond attributes
----
