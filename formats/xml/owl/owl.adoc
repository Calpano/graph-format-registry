= OWL (Web Ontology Language)
:toc:

A W3C knowledge-representation language for ontologies, layered on RDF. Classes,
individuals and properties are resources (nodes) and axioms/property assertions
are directed, predicate-typed edges. Most commonly serialised as RDF/XML
(`.owl`), but also Turtle, Manchester or OWL/XML syntax; it is the basis of
link:../../xml/biopax/biopax-l3.adoc[BioPAX] and a sibling of the
link:../../xml/rdf-xml/rdf-xml.adoc[RDF/XML] serialisation.

== Features

[source]
----
format:owl ..lacks.. multiple-graphs-per-document ,, One ontology per document; reuse via owl:imports
format:owl ..supports.. nodes ,, Classes, individuals and properties (resources)
format:owl ..lacks.. undirected-edges
format:owl ..supports.. directed-edges ,, RDF triples / property assertions are directed
format:owl ..lacks.. mixed-directionality-edges
format:owl ..lacks.. hyperedges
format:owl ..supports.. parallel-edges ,, RDF/OWL based: distinct predicates may connect the same two resources
format:owl ..supports.. self-loops ,, RDF/OWL based: a triple may have subject == object
format:owl ..supports.. edges-on-edges ,,
..status.. partial
OWL 2 axiom annotations / RDF reification
,,
format:owl ..lacks.. nested-graphs-in-nodes
format:owl ..lacks.. nested-graphs-in-edges
format:owl ..lacks.. nested-graphs-in-graphs
format:owl ..lacks.. node-labels ,, rdfs:label is data, not syntax
format:owl ..supports.. edge-labels ,, Predicate IRI names the edge
format:owl ..supports.. attributes-on-nodes ,, Data-property assertions (literals on resources)
format:owl ..lacks.. attributes-on-edges
format:owl ..lacks.. attributes-on-graphs
format:owl ..supports.. typed-edges ,, Object properties; every triple typed by its predicate
----
