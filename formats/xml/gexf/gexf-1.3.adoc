= GEXF 1.3
:toc:

XML-based format for Gephi, supporting dynamic graphs and hierarchy.

== Identity

[source]
----
format:gexf ..has type.. format
format:gexf ..category.. xml
format:gexf ..label.. GEXF
format:gexf ..alternative name.. Graph Exchange XML Format
format:gexf ..wikidata.. Q28757774

format:gexf-1.3 ..version of.. format:gexf
format:gexf-1.3 ..version.. 1.3
format:gexf-1.3 ..file extension.. .gexf
format:gexf-1.3 ..spec.. http://gexf.net/schema.html
----

== Features

[source]
----
format:gexf-1.3 ..lacks.. multiple-graphs-per-document ,, One graph per file
format:gexf-1.3 ..supports.. nodes
format:gexf-1.3 ..supports.. undirected-edges ,, Via defaultedgetype="undirected"
format:gexf-1.3 ..supports.. directed-edges ,, Via defaultedgetype="directed"
format:gexf-1.3 ..lacks.. hyperedges
format:gexf-1.3 ..supports.. mixed-directionality-edges ,, Per-edge type attribute overrides default
format:gexf-1.3 ..lacks.. edges-on-edges
format:gexf-1.3 ..supports.. nested-graphs-in-nodes ,, Hierarchy module (compound nodes)
format:gexf-1.3 ..lacks.. nested-graphs-in-edges
format:gexf-1.3 ..lacks.. nested-graphs-in-graphs
format:gexf-1.3 ..supports.. node-labels ,, Via label attribute
format:gexf-1.3 ..supports.. edge-labels ,, Via label attribute
format:gexf-1.3 ..supports.. attributes-on-nodes ,, Via <attvalues>
format:gexf-1.3 ..supports.. attributes-on-edges ,, Via <attvalues>
format:gexf-1.3 ..supports.. attributes-on-graphs ,, Via <attributes>
format:gexf-1.3 ..supports.. typed-edges ,, Via kind attribute (GEXF 1.3)
----
