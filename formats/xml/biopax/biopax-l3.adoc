= BioPAX Level 3
:toc:

BioPAX is an OWL-based standard for representing biological pathways such as
metabolic, signaling and gene-regulatory networks. Pathways are modelled as
RDF/OWL graphs of typed entities (proteins, small molecules, complexes) linked
by interactions and conversions.

== Features

[source]
----
format:biopax-l3 ..supports.. multiple-graphs-per-document ,, Multiple Pathway instances per OWL document
format:biopax-l3 ..supports.. nodes ,, Physical entities and interactions as OWL individuals
format:biopax-l3 ..supports.. directed-edges ,, Conversion (left/right, conversionDirection) and Control (controlType)
format:biopax-l3 ..supports.. undirected-edges ,, MolecularInteraction is non-directional
format:biopax-l3 ..supports.. hyperedges ,, Interactions link multiple participants
format:biopax-l3 ..supports.. nested-graphs-in-graphs ,, pathwayComponent nests sub-pathways
format:biopax-l3 ..supports.. node-labels ,, displayName / standardName
format:biopax-l3 ..supports.. edge-labels ,, Interactions are Entities with displayName / standardName
format:biopax-l3 ..supports.. attributes-on-nodes ,, OWL datatype and object properties
format:biopax-l3 ..supports.. attributes-on-edges ,, Interaction properties (controlType, evidence, comment)
format:biopax-l3 ..supports.. attributes-on-graphs ,, Pathway properties (organism, displayName, comment)
format:biopax-l3 ..supports.. typed-edges ,, Interaction subclasses (Control, Conversion, etc.)
format:biopax-l3 ..lacks.. mixed-directionality-edges
format:biopax-l3 ..supports.. parallel-edges ,, RDF/OWL based: distinct predicates (interactions) may connect two entities
format:biopax-l3 ..supports.. self-loops ,, RDF/OWL based: an entity can be both subject and object of an interaction
format:biopax-l3 ..lacks.. edges-on-edges
format:biopax-l3 ..lacks.. nested-graphs-in-nodes
format:biopax-l3 ..lacks.. nested-graphs-in-edges
----
