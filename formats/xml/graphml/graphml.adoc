= GraphML
:toc:

Family entry for GraphML. The released versions are link:graphml-1.0.adoc[GraphML 1.0] and
link:graphml-1.1.adoc[GraphML 1.1], each with its own XSD/DTD.

GraphML is an XML-based file format for graphs. It consists of a language core
to describe the structural properties of a graph and a flexible extension
mechanism to add application-specific data.

It is widely used for representing graph structures and is supported by various
graph visualization and analysis tools.
