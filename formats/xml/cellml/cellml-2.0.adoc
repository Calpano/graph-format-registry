= CellML 2.0
:toc:

CellML is an XML-based language for describing mathematical models of
biological systems. A model is built from components holding variables and
MathML equations, wired together through connections that map variables across
component boundaries, forming a network of coupled components.

== Features

[source]
----
format:cellml-2.0 ..supports.. nodes ,, component elements
format:cellml-2.0 ..supports.. undirected-edges ,, connection elements map variables between two components
format:cellml-2.0 ..supports.. node-labels ,, name attribute on components
format:cellml-2.0 ..supports.. nested-graphs-in-nodes ,, encapsulation hierarchy of components
format:cellml-2.0 ..supports.. attributes-on-nodes ,, variables and units within components
format:cellml-2.0 ..supports.. attributes-on-edges ,, component_1/component_2 and map_variables on connection
format:cellml-2.0 ..supports.. attributes-on-graphs ,, model name and metadata
format:cellml-2.0 ..lacks.. multiple-graphs-per-document
format:cellml-2.0 ..lacks.. directed-edges
format:cellml-2.0 ..lacks.. hyperedges
format:cellml-2.0 ..lacks.. mixed-directionality-edges
format:cellml-2.0 ..lacks.. parallel-edges ,, At most one connection per component pair; map_variables are grouped within it, not separate edges

format:cellml-2.0 ..lacks.. edges-on-edges
format:cellml-2.0 ..lacks.. nested-graphs-in-edges
format:cellml-2.0 ..lacks.. nested-graphs-in-graphs
format:cellml-2.0 ..lacks.. typed-edges
----
