= SBOL (Synthetic Biology Open Language) 3.1
:toc:

SBOL is an RDF-based standard for exchanging synthetic-biology design
information. Designs are captured as a graph of Components linked by
SubComponents, Interactions and Constraints, serialized using Semantic Web
technologies and commonly stored as link:../../xml/rdf-xml/rdf-xml.adoc[RDF/XML].

== Features

[source]
----
format:sbol-3.1 ..supports.. multiple-graphs-per-document ,, Multiple top-level objects per RDF document
format:sbol-3.1 ..supports.. nodes ,, Component and other top-level objects as RDF resources
format:sbol-3.1 ..supports.. directed-edges ,, Interaction participations with SBO roles
format:sbol-3.1 ..supports.. hyperedges ,, Interactions link multiple participants
format:sbol-3.1 ..supports.. edges-on-edges ,, 3.1 lets a Participation reference an Interaction (higher-order interactions)
format:sbol-3.1 ..supports.. nested-graphs-in-nodes ,, SubComponent hierarchy within Components
format:sbol-3.1 ..supports.. node-labels ,, name / displayId
format:sbol-3.1 ..supports.. edge-labels ,, name / displayId on Interaction
format:sbol-3.1 ..supports.. attributes-on-nodes ,, RDF properties on objects
format:sbol-3.1 ..supports.. attributes-on-edges ,, Interaction and Participation RDF properties
format:sbol-3.1 ..supports.. attributes-on-graphs ,, RDF properties on the containing Component
format:sbol-3.1 ..supports.. typed-edges ,, Interaction and participation types from SBO
format:sbol-3.1 ..lacks.. undirected-edges
format:sbol-3.1 ..lacks.. mixed-directionality-edges
format:sbol-3.1 ..lacks.. nested-graphs-in-edges
format:sbol-3.1 ..lacks.. nested-graphs-in-graphs
----
