= sparse6
:toc:

A binary format for undirected graphs, designed by Brendan McKay for the nauty
toolkit. Like link:../../binary/graph6/graph6.adoc[graph6] it bit-packs the graph and then ASCII-armors it into
printable characters, but it is optimized for sparse graphs by encoding the edge
list rather than the full adjacency matrix. Categorized as `binary` because,
despite using printable characters, it is bit-packed and not human-readable.
