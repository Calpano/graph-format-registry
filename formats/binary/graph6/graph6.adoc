= Graph6
:toc:

A binary format for undirected graphs: the adjacency matrix is packed into a
bit vector, then ASCII-armored (each 6-bit group shifted by +63 into printable
characters). Categorized as `binary` because, despite using printable
characters, it is bit-packed and not human-readable.
