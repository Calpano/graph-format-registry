= digraph6
:toc:

A binary format for directed graphs, designed by Brendan McKay for the nauty
toolkit. It bit-packs the full (possibly asymmetric) adjacency matrix and then
ASCII-armors it into printable characters, making it the directed counterpart of
link:../../binary/graph6/graph6.adoc[graph6]. Categorized as `binary` because, despite using printable
characters, it is bit-packed and not human-readable.
