= Connected JSON 8.0.0
:toc:

Connected JSON (CJ) is a JSON format used to model graph data structures. CJ is the logical successor to link:../../xml/graphml/graphml.adoc[GraphML]. The conceptual model of both formats is almost identical. CJ, being designed 20 years later, is more flexible for adding JSON data to graph entities.

See the current spec. GraphInOut implements the v0.5 strict variant.

None of the existing JSON graph interchange formats has the same breadth of features as the over 20-year-old XML-based link:../../xml/graphml/graphml.adoc[GraphML]. Connected JSON aims to be a full link:../../xml/graphml/graphml.adoc[GraphML] replacement. It supports the semantic capabilities and data representation found in link:../../xml/graphml/graphml.adoc[GraphML], while adopting a more flexible, schema-less JSON approach for attaching data to graph entities.

== Features

[source]
----
format:connected-json-8.0.0 ..supports.. multiple-graphs-per-document ,, Via graphs array
format:connected-json-8.0.0 ..supports.. nodes
format:connected-json-8.0.0 ..supports.. undirected-edges ,, Via undir endpoint direction
format:connected-json-8.0.0 ..supports.. directed-edges ,, Via in/out endpoint directions
format:connected-json-8.0.0 ..supports.. hyperedges ,, N-ary endpoints
format:connected-json-8.0.0 ..supports.. mixed-directionality-edges ,, Each endpoint specifies own direction
format:connected-json-8.0.0 ..supports.. parallel-edges ,, Distinct edge objects may share endpoints
format:connected-json-8.0.0 ..supports.. self-loops ,, An edge may reference the same node twice
format:connected-json-8.0.0 ..lacks.. edges-on-edges
format:connected-json-8.0.0 ..supports.. nested-graphs-in-nodes ,, Via graphs property (compound nodes)
format:connected-json-8.0.0 ..supports.. nested-graphs-in-edges ,, Via graphs property (compound edges)
format:connected-json-8.0.0 ..supports.. nested-graphs-in-graphs
format:connected-json-8.0.0 ..supports.. node-labels ,, Multilingual support
format:connected-json-8.0.0 ..supports.. edge-labels ,, Multilingual support
format:connected-json-8.0.0 ..supports.. attributes-on-nodes ,, Via data property
format:connected-json-8.0.0 ..supports.. attributes-on-edges ,, Via data property
format:connected-json-8.0.0 ..supports.. attributes-on-graphs ,, Via data property
format:connected-json-8.0.0 ..supports.. typed-edges ,, Via type, typeUri, typeNode
----
