= Connected JSON5
:toc:

A JSON5-syntax variant of link:../../json/connected-json/connected-json-8.0.0.adoc[Connected JSON]. It shares the Connected JSON graph
model (nodes, edges with directional endpoints, and nested graphs) but is
written in JSON5, allowing comments, unquoted keys and trailing commas.

== Identity

[source]
----
format:connected-json5 ..has type.. format
format:connected-json5 ..category.. json
format:connected-json5 ..label.. Connected JSON5
format:connected-json5 ..alternative name.. CJ5
format:connected-json5 ..file extension.. .cj.json5
format:connected-json5 ..file extension.. .json5
format:connected-json5 ..org.. calpano
format:connected-json5 ..spec.. https://j-s-o-n.org/connected-json/8.0.0/
----

== Features

[source]
----
format:connected-json5 ..supports.. multiple-graphs-per-document ,, Via graphs array
format:connected-json5 ..supports.. nodes
format:connected-json5 ..supports.. undirected-edges ,, Via undir endpoint direction
format:connected-json5 ..supports.. directed-edges ,, Via in/out endpoint directions
format:connected-json5 ..supports.. hyperedges ,, N-ary endpoints
format:connected-json5 ..supports.. mixed-directionality-edges ,, Each endpoint specifies own direction
format:connected-json5 ..supports.. parallel-edges ,, Distinct edge objects may share endpoints
format:connected-json5 ..supports.. self-loops ,, An edge may reference the same node twice
format:connected-json5 ..lacks.. edges-on-edges
format:connected-json5 ..supports.. nested-graphs-in-nodes ,, Via graphs property (compound nodes)
format:connected-json5 ..supports.. nested-graphs-in-edges ,, Via graphs property (compound edges)
format:connected-json5 ..supports.. nested-graphs-in-graphs
format:connected-json5 ..supports.. node-labels ,, Multilingual support
format:connected-json5 ..supports.. edge-labels ,, Multilingual support
format:connected-json5 ..supports.. attributes-on-nodes ,, Via data property
format:connected-json5 ..supports.. attributes-on-edges ,, Via data property
format:connected-json5 ..supports.. attributes-on-graphs ,, Via data property
format:connected-json5 ..supports.. typed-edges ,, Via type, typeUri, typeNode
----
