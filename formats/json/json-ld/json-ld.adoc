= JSON-LD
:toc:

A JSON-based serialization of RDF that maps JSON keys to IRIs via a context.
Resources are nodes and triples are directed edges typed by their predicate.
Supports named graphs through the @graph keyword.

== Features

[source]
----
format:json-ld ..supports.. multiple-graphs-per-document ,, Named graphs via @graph
format:json-ld ..supports.. nodes ,, Node objects (IRIs and blank nodes)
format:json-ld ..lacks.. undirected-edges
format:json-ld ..supports.. directed-edges ,, Triples are directed subject to object
format:json-ld ..lacks.. hyperedges
format:json-ld ..lacks.. mixed-directionality-edges
format:json-ld ..supports.. parallel-edges ,, Via distinct predicates between the same two nodes
format:json-ld ..supports.. self-loops ,, A triple with subject equal to object
format:json-ld ..supports.. edges-on-edges ,,
..status.. partial
Via RDF reification (rdf:Statement)
,,
format:json-ld ..lacks.. nested-graphs-in-nodes
format:json-ld ..lacks.. nested-graphs-in-edges
format:json-ld ..lacks.. nested-graphs-in-graphs ,, RDF datasets are flat; named graphs are not nested
format:json-ld ..lacks.. node-labels ,, No native label slot; rdfs:label is data, not syntax
format:json-ld ..supports.. edge-labels ,, Predicate IRI names the edge
format:json-ld ..supports.. attributes-on-nodes ,, Literal-valued properties on node objects
format:json-ld ..lacks.. attributes-on-edges ,, Edge is the predicate; no per-triple attributes except via reification
format:json-ld ..supports.. attributes-on-graphs ,,
..status.. partial
Properties asserted about the graph name @id
,,
format:json-ld ..supports.. typed-edges ,, Every triple is typed by its predicate
----
