= RDF/JSON
:toc:

A JSON serialization of RDF that encodes a graph as an object keyed by subject,
then predicate, with arrays of object values. Resources are nodes and triples
are directed edges typed by their predicate. Distinct from link:../../json/json-ld/json-ld.adoc[JSON-LD].

== Identity

[source]
----
format:rdf-json ..has type.. format
format:rdf-json ..category.. json
format:rdf-json ..label.. RDF/JSON
format:rdf-json ..file extension.. .rj
format:rdf-json ..media type.. application/rdf+json
format:rdf-json ..wikidata.. Q50322163
format:rdf-json ..org.. W3C
format:rdf-json ..spec.. https://www.w3.org/TR/rdf-json/
----

== Features

[source]
----
format:rdf-json ..lacks.. multiple-graphs-per-document ,, No named graphs; single graph per document
format:rdf-json ..supports.. nodes ,, Resources (IRIs and blank nodes)
format:rdf-json ..lacks.. undirected-edges
format:rdf-json ..supports.. directed-edges ,, Triples are directed subject to object
format:rdf-json ..lacks.. hyperedges
format:rdf-json ..lacks.. mixed-directionality-edges
format:rdf-json ..supports.. edges-on-edges ,,
..status.. partial
Via RDF reification (rdf:Statement)
,,
format:rdf-json ..lacks.. nested-graphs-in-nodes
format:rdf-json ..lacks.. nested-graphs-in-edges
format:rdf-json ..lacks.. nested-graphs-in-graphs
format:rdf-json ..lacks.. node-labels ,, No native label slot; rdfs:label is data, not syntax
format:rdf-json ..supports.. edge-labels ,, Predicate IRI names the edge
format:rdf-json ..supports.. attributes-on-nodes ,, Literal-valued properties on resources
format:rdf-json ..lacks.. attributes-on-edges ,, Edge is the predicate; no per-triple attributes except via reification
format:rdf-json ..lacks.. attributes-on-graphs
format:rdf-json ..supports.. typed-edges ,, Every triple is typed by its predicate
----
