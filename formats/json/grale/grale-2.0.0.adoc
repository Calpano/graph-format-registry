= grale 2.0.0
:toc:

See link:grale.adoc[grale] for the family-level identity. This entry covers the
2.0.0 release (current). Changes vs link:grale-1.0.0.adoc[1.0.0]: the opaque
passthrough label field `meta` is renamed `data` (grale-reserved keys under
`data.grale`, engine settings under `data.grale.engine`) — the breaking change
of the release — and the graph label gains an optional `edgeRouting`
(`orthogonal` | `polyline` | `spline`) routing-style hint. The structural
feature set is unchanged.
