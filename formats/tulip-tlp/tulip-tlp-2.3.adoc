= Tulip TLP 2.3
:toc:

Plain-text format of the link:../../tools.adoc#_tulip[Tulip] graph visualization software, using a parenthesized
S-expression-like syntax. Nodes are integer indices, edges carry an id with source
and target, and properties hold typed values per node and per edge.

== Identity

[source]
----
format:tulip-tlp ..has type.. format
format:tulip-tlp ..category.. text
format:tulip-tlp ..label.. Tulip TLP
format:tulip-tlp ..alternative name.. TLP
format:tulip-tlp ..org.. University of Bordeaux

format:tulip-tlp-2.3 ..version of.. format:tulip-tlp
format:tulip-tlp-2.3 ..version.. 2.3
format:tulip-tlp-2.3 ..file extension.. .tlp
format:tulip-tlp-2.3 ..spec.. https://tulip.labri.fr/site/?q=tlp-file-format
----

== Features

[source]
----
format:tulip-tlp-2.3 ..lacks.. multiple-graphs-per-document ,, One root graph with subgraph hierarchy
format:tulip-tlp-2.3 ..supports.. nodes ,, Integer index list
format:tulip-tlp-2.3 ..supports.. undirected-edges ,,
..status.. partial
Edges store source/target; undirected use is application-level
,,
format:tulip-tlp-2.3 ..supports.. directed-edges ,, Ordered source/target pairs
format:tulip-tlp-2.3 ..lacks.. hyperedges
format:tulip-tlp-2.3 ..lacks.. edges-on-edges
format:tulip-tlp-2.3 ..lacks.. nested-graphs-in-nodes
format:tulip-tlp-2.3 ..lacks.. nested-graphs-in-edges
format:tulip-tlp-2.3 ..supports.. nested-graphs-in-graphs ,, Cluster/subgraph hierarchy
format:tulip-tlp-2.3 ..supports.. node-labels ,, viewLabel property
format:tulip-tlp-2.3 ..supports.. edge-labels ,, viewLabel property
format:tulip-tlp-2.3 ..supports.. attributes-on-nodes ,, Properties per node
format:tulip-tlp-2.3 ..supports.. attributes-on-edges ,, Properties per edge
format:tulip-tlp-2.3 ..supports.. attributes-on-graphs ,,
..status.. partial
Properties scoped per cluster
,,
format:tulip-tlp-2.3 ..lacks.. typed-edges
----
