= TriG
:toc:

An extension of link:../turtle/turtle.adoc[Turtle] for serializing RDF datasets, grouping triples into one
or more named graphs. Resources are nodes and triples are directed edges typed
by their predicate.

== Identity

[source]
----

== Features

[source]
----
format:trig ..supports.. multiple-graphs-per-document ,, Named graphs are the core feature
format:trig ..supports.. nodes ,, Resources (IRIs and blank nodes)
format:trig ..lacks.. undirected-edges
format:trig ..supports.. directed-edges ,, Triples are directed subject to object
format:trig ..lacks.. hyperedges
format:trig ..lacks.. mixed-directionality-edges
format:trig ..supports.. edges-on-edges ,,
..status.. partial
Via RDF reification (rdf:Statement)
,,
format:trig ..lacks.. nested-graphs-in-nodes
format:trig ..lacks.. nested-graphs-in-edges
format:trig ..lacks.. nested-graphs-in-graphs ,, Named graphs are a flat set, not nested
format:trig ..lacks.. node-labels ,, No native label slot; rdfs:label is data, not syntax
format:trig ..supports.. edge-labels ,, Predicate IRI names the edge
format:trig ..supports.. attributes-on-nodes ,, Literal-valued properties on resources
format:trig ..lacks.. attributes-on-edges ,, Edge is the predicate; no per-triple attributes except via reification
format:trig ..supports.. attributes-on-graphs ,,
..status.. partial
Properties asserted about a graph name IRI
,,
format:trig ..supports.. typed-edges ,, Every triple is typed by its predicate
----
