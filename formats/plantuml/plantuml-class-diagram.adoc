= PlantUML Class Diagram
:toc:

The class-diagram type of link:plantuml.adoc[PlantUML]. Classes, interfaces and
enums are nodes (each carrying a `uml:kind` and its member fields/methods);
relationships between them — inheritance, realization, composition, aggregation,
association, dependency — are directed, typed edges. link:../../tools.adoc#_graphinout[GraphInOut]'s
`reader-plantuml` parses these with the official PlantUML library (parse only, no
rendering), and is the analogue of link:../mermaid/mermaid-class.adoc[Mermaid Class Diagram].

== Identity

[source]
----
format:plantuml-class-diagram ..has type.. format
format:plantuml-class-diagram ..subformat of.. format:plantuml
format:plantuml-class-diagram ..category.. text
format:plantuml-class-diagram ..label.. PlantUML Class Diagram
format:plantuml-class-diagram ..spec.. https://plantuml.com/class-diagram
----

== Features

[source]
----
format:plantuml-class-diagram ..supports.. multiple-graphs-per-document ,, Multiple @startuml..@enduml blocks
format:plantuml-class-diagram ..supports.. nodes ,, class / interface / enum / abstract class
format:plantuml-class-diagram ..supports.. undirected-edges ,, Plain association (--)
format:plantuml-class-diagram ..supports.. directed-edges ,, Relationships are oriented
format:plantuml-class-diagram ..supports.. mixed-directionality-edges ,, A diagram can mix -- and -->
format:plantuml-class-diagram ..lacks.. hyperedges
format:plantuml-class-diagram ..lacks.. edges-on-edges
format:plantuml-class-diagram ..lacks.. nested-graphs-in-nodes
format:plantuml-class-diagram ..lacks.. nested-graphs-in-edges
format:plantuml-class-diagram ..supports.. nested-graphs-in-graphs ,, package / namespace grouping
format:plantuml-class-diagram ..supports.. node-labels ,, Display name via "Label" as Alias
format:plantuml-class-diagram ..supports.. edge-labels ,, Relationship label after :
format:plantuml-class-diagram ..supports.. attributes-on-nodes ,, Class members (fields/methods) and uml:kind
format:plantuml-class-diagram ..supports.. attributes-on-edges ,,
..status.. partial
Multiplicities / roles
,,
format:plantuml-class-diagram ..lacks.. attributes-on-graphs
format:plantuml-class-diagram ..supports.. typed-edges ,, extension / realization / composition / aggregation / association / dependency
----
