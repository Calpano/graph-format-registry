= Tools
:toc:

Tools that read and/or write the graph formats in this registry, and which
formats each one handles. Format objects are qualified format ids in the
`format:` namespace (e.g. `format:graphml`), built from the `format-id` slugs in
`catalog.adoc`.

Tool-entry triple shape:

[cols="1,3",options="header"]
|===
| Predicate | Object / meaning

| `..has type..` | `tool`
| `..label..`    | Display label
| `..repo..`     | Source repository URL (GitHub unless noted)
| `..reads..`    | Repeatable; one triple per format the tool can import
| `..writes..`   | Repeatable; one triple per format the tool can export
|===

NOTE: The read/write coverage below is a first pass transcribed from each
tool's documentation and still needs verification format-by-format. A format
appearing under both `..reads..` and `..writes..` means round-trip support.
