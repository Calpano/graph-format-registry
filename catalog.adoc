= Format Catalog

Every format and model we currently know, with its identity fields as found in the Connected JSON source (`cc-gio-ui/src/lib/data/format-*.json`).
This is the working sheet for **fixing and homogenizing ids**.
Each entry lives at
`formats/<category>/<family>/<format-id>.adoc`.

Columns:

* *format-id* — the canonical slug.
Without `format:` it becomes the AsciiDoc filename (`<format-id>.adoc`).
Includes the version suffix where the format has one.
* *version* — spec version, when the format has one.
* *released* — release date of that version, ISO 8601 (partial like `2025-04` allowed); blank = unknown.
* *cat* — category: `text` | `json` | `xml` | `binary`.
* *label* — display label.
* *alt names* — alternative names.

Formats and models are listed separately below — a *model* is a conceptual graph model, not a serialisation, and its ddot subject uses the `model:` namespace.

== Categories
To manage the large list of formats, we group them by category:

[plantuml]
....
hide empty members
hide circle
left to right direction

class binary
class text
class json
class xml
binary <|-- text
text <|-- json
text <|-- xml
....

`binary` includes formats that bit-pack their data and then ASCII-armor it (the graph6/sparse6/digraph6 family) — technically printable, but not human-readable text.

== Notes

* `mermaid` is an umbrella that the `reader-mermaid` parsers split into eight diagram-type sub-formats, each `..subformat of.. format:mermaid`:
`mermaid-flowchart`, `mermaid-class`, `mermaid-state`, `mermaid-er`,
`mermaid-c4`, `mermaid-mindmap`, `mermaid-sankey`, `mermaid-architecture`.
* *Versions checked against each homepage (2026-06):* biogrid-tab 3.0 (latest), gexf 1.3 (1.1 deprecated; 1.3 recommended), gjgf 0.1, gxl 1.0 (Dagstuhl-ratified), ocif 0.6 (Candidate Recommendation, Apr 2025), psimi-tab 2.5 (2.6/2.7 exist downstream but our entry is 2.5), sbml Level 3 Version 2 Release 2 (2019-03-29).
Release dates still mostly need filling in.
* *GraphML:* two released versions, 1.0 and 1.1, each with its own XSD/DTD — `graphml-1.0` and `graphml-1.1`.
* *JGF:* a v1 and a revised v2 — `jgf-1.0` and `jgf-2.0` (v2 updated Jan 2020; GitHub releases still tagged 1.0).
* *XGMML:* treated as v1 — `xgmml-1.0`.
* *DOT has no standalone version:* the language evolves with Graphviz (HTML-like labels, new attributes are tied to Graphviz releases).
Graphviz is currently at 15.0.0. `dot` stays an unversioned id; the version lives on the Graphviz tool.
* Label casing is inconsistent (`CytoScape JSON` vs `VOSviewer JSON`, bare acronyms like `GDF`/`GML`) — homogenize once ids are settled.
