= Graph Format Registry
:toc:

A catalog of graph, network and graph-adjacent file formats (and the tools that
read and write them), captured as human-readable AsciiDoc *and* a machine-readable
https://ddot.it[ddot] knowledge graph in the same files.

== What's here

[cols="1,3",options="header"]
|===
| File / directory | Contents

| `formats/<family>/<format-id>.adoc` | One entry per format (identity + feature triples + prose). Sample data files may sit alongside.
| link:tools.adoc[`tools.adoc`]                 | Tools that read/write the formats, with `..reads..` / `..writes..` links.
| link:graph-features.adoc[`graph-features.adoc`] | The controlled vocabulary of graph-model features every format is scored against.
| link:catalog.adoc[`catalog.adoc`]             | The index of all known formats.
| link:SCHEMA.adoc[`SCHEMA.adoc`]               | The normative entry schema — read this before adding an entry.
| link:how-to-contribute.adoc[`how-to-contribute.adoc`] | Step-by-step guide for adding a format, plus the conventions in brief.
| link:LICENSE[`LICENSE`]                       | CC0 1.0 Universal public-domain dedication.
|===

Each entry carries two layers: prose/tables for humans, and ddot triples inside
`[source]` / `----` code blocks for machines. The triple subject is the format's
id in the `format:` namespace (e.g. `format:graphml`); conceptual models use
`model:` (e.g. `model:neo4j`).

== Motivation
There are so many different graph formats. An app wanting to support many formats (such as https://graphinout.com[graphinout.com]) needs stable identifiers, links to specs and some more infos.
This repository is meant as a central, shared registry for graph formats.


== Method
A great 2015 paper on graph file formats: https://arxiv.org/pdf/1503.02781.pdf[]
including links to graph data repositories or time frames indicates when the format was/is used.
Furthermore, I looked into import/export lists of existing tools, then broadened that list by looking in Wikipedia and Wikidata for entries in the same categories.
The result is, to my knowledge, the most comprehensive list of graph formats on the web.

== Contributing

**New formats are welcome via pull request.** See
link:how-to-contribute.adoc[how-to-contribute.adoc] for the step-by-step guide
to adding an entry and a summary of the registry's conventions, and
link:SCHEMA.adoc[SCHEMA.adoc] for the full normative schema. Corrections to
existing entries are equally welcome.
